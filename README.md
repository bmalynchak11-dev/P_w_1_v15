# Стартовий проєкт

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально на Linux/WSL2: `pip install -r requirements.txt`.
2. Знайдіть у теці `variants/` теку свого номера (`variant_NN/`) і реалізуйте файли за карткою варіанта. Файл `variant_NN.py` службовий, його не змінюйте.
3. Запускайте відкриті тести: `pytest` (або `pytest tests/test_variant_NN.py`).
4. Змінюйте лише файли у своїй теці і файл `ANSWERS.md`.
